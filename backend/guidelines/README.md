# Guidelines

This folder contains raw TU BCA guideline PDFs, extracted rule files, and example reports.

## Structure

- source/  Raw official PDFs (do not delete)
- rules/   Structured JSON rules used by the app
- examples/  Sample reports for RAG (good/bad)

## Rule Files

- rules/common/format.json: shared formatting rules (font, margins, spacing, page numbering)
- rules/4th_sem/: semester-specific rules
- rules/6th_sem/: semester-specific rules
- rules/8th_sem/: semester-specific rules
